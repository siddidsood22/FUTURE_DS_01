# FUTURE_DS_01 - Business Sales Performance Analytics

## 📌 Project Overview
This project analyzes business sales data to identify revenue trends, top-selling products, high-value categories, and regional performance.

## 🎯 Objectives
- Analyze sales performance
- Identify top-performing products
- Compare regional sales
- Generate business insights
- Recommend strategies to improve sales

## 🛠 Tools Used
- Microsoft Excel
- Tableau
- GitHub

## 📂 Dataset
Business Sales Dataset

## 📊 Dashboard Features
- Total Sales
- Total Profit
- Total Orders
- Top Products
- Regional Performance
- Category Performance
- Monthly Sales Trend

## 📈 Key Insights
- Identified best-selling products.
- Compared sales performance across regions.
- Found the highest revenue-generating categories.
- Analyzed monthly sales trends.

## 💡 Business Recommendations
- Increase inventory for top-performing products.
- Focus marketing efforts on profitable regions.
- Improve performance of low-selling categories.
