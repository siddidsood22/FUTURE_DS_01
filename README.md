🛒 E-Commerce Sales Dashboard using Excel
📌 Project Overview

This project analyzes an e-commerce sales dataset to uncover business insights and support data-driven decision-making. Using Microsoft Excel, the raw sales data was cleaned, transformed, and visualized through an interactive dashboard that highlights key performance indicators (KPIs), sales trends, top-performing products, customer behavior, and country-wise revenue.

The goal of this project is to demonstrate practical business analytics skills by converting raw transactional data into meaningful insights for stakeholders.

🎯 Objectives
Clean and prepare raw sales data.
Calculate business KPIs.
Analyze monthly revenue trends.
Identify top-selling products.
Analyze revenue by country.
Identify high-value customers.
Present insights through a professional dashboard.

📂 Dataset Information

The dataset contains e-commerce transaction records with the following fields:

Invoice Number
Product Description
Quantity
Invoice Date
Unit Price
Customer ID
Country
🧹 Data Cleaning Process

The following cleaning steps were performed before analysis:

Removed cancelled orders (Invoice Number starting with "C")
Removed duplicate records
Removed rows with Quantity ≤ 0
Removed rows with Unit Price ≤ 0
Converted Invoice Date into Month-Year format
Created a Revenue column using:

Revenue = Quantity × Unit Price

🔍 Key Insights
The business generated over 10.6 million in total revenue.
Nearly 20,000 customer orders were processed.
More than 4,300 unique customers contributed to sales.
The United Kingdom generated the highest revenue, making it the primary market.
A small number of products contributed significantly to overall revenue, indicating a Pareto (80/20) distribution.
Sales increased steadily throughout the year, with a noticeable peak during November, likely driven by seasonal shopping and holiday demand.
💡 Business Recommendations
Increase inventory for the highest-performing products.
Focus marketing campaigns on top-performing countries.
Introduce loyalty programs for repeat customers.
Prepare inventory ahead of peak sales months.
Expand sales efforts into emerging markets to reduce dependence on a single country.
Bundle complementary products to increase the average order value.
